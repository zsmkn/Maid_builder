# 實機驗收清單

照順序玩一輪就能把待驗收項目走過一遍。發現問題時在該項底下記一行（現象＋座標／截圖），之後再一起排修。
建議開新的生存世界（另開一個創造世界做 §7 的壓力測試），並先準備：TLM 女僕 2～3 隻、藍圖魔杖、羽毛筆、幾箱基本材料（橡木、圓石、玻璃、泥土）與鷹架。

---

## 1. 領地起步（Lv1）

- [ ] 放旗幟：成功放下；在距離 < 10 區塊的地方放第二支會被拒絕並顯示原因。
- [ ] 右鍵旗幟開啟領地介面，各分頁都能切換、文字沒有跑版或缺翻譯。
- [ ] 領地邊界線在玩家附近顯示正常。
- [ ] 「綁定材料箱」：右鍵容器加入／移除，潛行＋右鍵結束；大箱子只算一個。

## 2. 建造模式

- [ ] 按 `Caps Lock` 進入建造模式。**用注音／新注音輸入法時**也試一次：會不會被攔截或切換大小寫？有衝突記下來（改預設鍵）。
- [ ] 模板跟著準星移動、底部貼在地面；`R` 旋轉、`M` 鏡像、`PgUp`／`PgDn` 調整高度順手。
- [ ] `B` 開材料清單，數量與材料箱內容相符。
- [ ] 超出領地、與其他建築重疊、蓋住旗幟、等級不夠時預覽變紅且不能放。
- [ ] 右鍵排入佇列；左鍵離開。
- [ ] 建設頁的佇列可以調整順序、取消。

## 3. 女僕建造（領地佇列）

- [ ] 「建築師」按鈕切換任務；女僕自動照佇列蓋，蓋完一棟接下一棟。
- [ ] **缺料取料**：材料用完時女僕自己去材料箱拿。特別測：女僕在蓋到一半的房子裡、材料箱在牆外、要從門繞出去（本次修正的情境）。也試樓梯、兩層樓、門關著的情況。
- [ ] 多隻女僕同時蓋：材料平均分、不擠在同一處、不互相卡位。
- [ ] 中途離開（走遠讓區塊卸載）再回來：工作繼續、進度沒掉。
- [ ] 存檔退出重進：工作、佇列、女僕綁定都還在。

## 4. 鷹架（7-1、7-5、7-8）

- [ ] 蓋高處時女僕搭鷹架、爬上去蓋、完工後拆掉並回收。
- [ ] 頂端沒得蓋時鷹架直接加高（7-5）。
- [ ] **橫向延伸**（7-8）：在懸空鷹架上行走會不會掉下去、卡在牆邊；下來前先走回落地的柱子。
- [ ] 完工回收時懸空的鷹架一起拆、不掉滿地。
- [ ] 取消工作（魔杖潛行＋右鍵兩次）：女僕停工並拆掉鷹架。

## 5. 各模板蓋完與運作（模板 v2）

每個模板蓋完後看外觀、確認登記為建築且「運作中」、繁榮度有增加：

- [ ] 倉庫（存放產物）
- [ ] 甘蔗田：女僕自己種、自己收。
- [ ] 小溫室／大溫室：農地保持濕潤；溫室加速（Lv3）有效。
- [ ] 伐木場
- [ ] 牧場／大牧場：餵食動物；繁殖冷卻縮短（Lv3）有效。
- [ ] 養蜂場：收蜂蜜時蜜蜂不會攻擊。
- [ ] 漁場：放在水邊時女僕坐船／坐墊找得到水。
- [ ] 居民宿舍：床、門正常。
- [ ] 涼亭（裝飾，Lv5）
- [ ] 含水、門、床、營火、蜂箱的方塊都放對方向；放水後女僕留下空桶。

## 6. 女僕工作與領地升級（G2～G4）

- [ ] 女僕指派到建築（工作地點選單）；任務相同且工作點在建築內會自動登記。
- [ ] 背包滿時回倉庫存放（只存 `products` 定義的產物），空位達 50% 自動回去工作。各工作任務（牧場、養蜂、釣魚、甘蔗）的產物是否都有涵蓋？
- [ ] 居民數、繁榮度數字合理（站在旗幟旁時應準確）。
- [ ] 升級：在旗幟繳交材料（背包＋材料箱扣除）→ 範圍擴大、解鎖新模板。
- [ ] 加成：女僕回血（Lv2）、不生成敵對生物（Lv4；刷怪籠照常）。
- [ ] 拆掉建築的幾個方塊 → 顯示「需修復」、加成停止；一鍵修復後恢復。
- [ ] **需玩家處理詳情**：修復時在建築裡放一個箱子擋住某格 → 佇列顯示「N 個需玩家處理」（滑鼠移上去有提示）且不會自己消失；點擊列出方塊、座標、原因（拆不了，目前是箱子）；「全部標示」後隔牆看到紅框；拿走箱子後幾秒內女僕自己補上、修復完成；另試「交回女僕重試」與「略過」（點兩次）。
- [ ] 拆掉旗幟 → 領地停用；在原位附近重放 → 恢復且不佔新名額。
- [ ] **數值手感**：升級節奏太快或太慢？哪一級卡最久？（記下來，之後調等級表）

## 7. 藍圖魔杖與羽毛筆（自訂藍圖）

- [ ] 魔杖選檔、預覽、確認建立工作；HUD 顯示正確／缺少／錯誤。
- [ ] 預覽 1000+ 方塊的大型藍圖時 FPS 是否可接受（Phase 3）。
- [ ] 拆除模式（7-7）：REPLACE 會替換錯誤方塊；ALL 的橘框預覽與實際清除範圍一致；容器、太硬的方塊不拆。
- [ ] 羽毛筆：對建築右鍵自動框選整棟、空中標記角落、推拉選區、存檔。
- [ ] 羽毛筆存出的檔案能用 Litematica 開啟（7-1）。
- [ ] 在領地內用魔杖放的工作會進領地佇列、使用領地材料箱，但不計繁榮度。

## 7.5 服務建築（1.2.0）

- [ ] 目錄「服務」分頁：五個建築的說明、解鎖等級正確。
- [ ] **食堂**：只有 Lv1 時女僕也會回血；Lv2 後更快。
- [ ] **村民集會所**：完工後不久有村民出現；之後每 20 分鐘一位，滿 3 位停止；村民會不會找到床與工作站點。
- [ ] **驛站**：完工後商人帶兩隻羊駝出現在庭院、不會跑出圍欄；約 20 分鐘後離開，30 分鐘後下一位。
- [ ] **驛站傳送**：在兩個領地各蓋一座；右鍵製圖台出現傳送畫面（顯示費用與距離），點選後扣 1 綠寶石並抵達；沒錢時畫面變紅不能點；潛行右鍵是一般製圖台；跨維度（例如地獄）也能傳。
- [ ] **瞭望塔**：晚上附近的怪物發光；用不祥之兆觸發襲擊時收到通知。
- [ ] **神社**：女僕好感度每天 +2（TLM 女僕介面查看）。
- [ ] 把任一建築拆壞（低於 80%）→ 效果停止；修復後恢復。
- [ ] **建材行**：沒有店員時右鍵切石機顯示「店沒開」；在女僕頁把女僕指派到建材行後可以開店；畫面分頁、搜尋、價格、今日剩餘量正確；Shift＋點擊買 4 組；晚上店員去睡覺時店關門；睡過夜後庫存補滿。
- [ ] **訂購缺料**：排一棟需要特殊方塊的建築（或用魔杖放自己的藍圖），缺料分頁列出缺少的材料，訂購後材料進到領地材料箱、女僕能拿去蓋。
- [ ] **價格手感**：2 綠寶石 16 個的價格、每日限量是否太緊或太鬆（記下來調整 `maidbuilder/shop/*.json`）。

## 8. 光影（7-5、7-6）

- [ ] 裝 Iris＋光影包：預覽、橘框／紅框、領地邊界正常顯示。
- [ ] 光影下鷹架加高、羽毛筆框選的手感。

- [ ] 伺服器重啟後工作、領地都還在。
