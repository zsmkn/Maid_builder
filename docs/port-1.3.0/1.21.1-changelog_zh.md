# Maid Builder 1.3.0 — 新介面與更快的施工

**需求：** Minecraft 1.21.1、NeoForge 21.1.219 以上、Touhou Little Maid 1.5.3 以上

從 1.2.0 升級時，世界存檔、領地與進行中的建造工作都可以直接沿用。

## 新功能

- **介面改版**（深色藍圖風格）：
  - **領地畫面**：分頁移到左側；總覽直接列出升級還差什麼；建造工作改成卡片，有進度條與明顯的「N 格需要你處理」按鈕；女僕卡片顯示背包。
  - **模板目錄**：分類、清單、詳情三欄並列。點一下查看建築（未解鎖的也能看），點兩下或按按鈕放置。
  - **材料清單**：進度條、帶數量的篩選（缺少／不夠／足夠／全部），每列用色條顯示材料在哪裡。
  - **魔杖與建造模式提示**：改成精簡的卡片，顯示進度、以物品圖示列出缺料、按鍵提示。
- **留給你處理的方塊不再消失**：有女僕放不了的方塊時，工作會留在佇列直到處理完。點擊可看每一格的原因、在世界中標示、交回女僕重試或略過。

## 改良

- **鷹架上施工快很多**（測試中高塔快 20–35%）：
  - 在鷹架頂端選到方塊就立刻放。
  - 鷹架搭在能蓋到最多方塊的位置，下來的次數變少。
  - 沿鷹架頂面移動時，先把柱子兩側蓋完再往外延伸。
  - 上鷹架前若身上材料不夠，會先到材料箱補齊。
- **不再提早在半空中放方塊**：女僕缺少目前這一層的材料時，不會先把工作檯、切石機放在還沒蓋的樓層位置，而是先去拿材料。
- **依使用順序拿材料**。背包滿了時，會把最晚才用到的材料放回箱子，不會站在箱子前不動。
- 繞路去材料箱時可以走過地毯與薄雪。

## 修正

- 門口台階是樓梯或半磚的建築（食堂、倉庫、宿舍、集會所），女僕可能站在室內不動。
- 鷹架現在會遵守領地保護類模組，搭建與拆除都是。
- 工作有留給玩家的方塊時切換拆除模式，可能導致該工作無法存檔。
- 極小的異常上傳檔可能讓伺服器預留大量記憶體。上傳檔的檢查也改到背景執行。
- 女僕剛拿完材料時可能放棄走向鷹架。
- 女僕可能在同一座鷹架反覆上下卻沒有放任何方塊。
